# Images Folder

## 📸 How to Add Your Photos

1. **Copy your photos** (JPG or PNG format) into this folder
2. **Name them** as: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, etc.
3. **Update the MemoryGallery.tsx** file to match your photo names

## Example:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- etc.

## Supported Formats:
- ✅ .jpg / .jpeg
- ✅ .png
- ✅ .webp

## Tips:
- Use square photos (1:1 ratio) for best display
- Recommended size: 800x800 pixels or larger
- Keep file sizes reasonable (under 2MB each)

## Where to Edit:
After adding photos, edit: `src/components/MemoryGallery.tsx`
Change the `src` values to match your photo names:
- `/images/photo1.jpg`
- `/images/photo2.jpg`
- etc.
